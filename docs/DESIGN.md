# نظام التصميم وتجربة الاستخدام

وثيقة القرارات خلف الواجهة: ما الذي تغيّر ولماذا، وكيف جرى التحقق منه.

## مبادئ تجربة الاستخدام

1. **الملخص قبل التفصيل.** لوحة التحكم تبدأ بجملة اليوم (ما ينتظر المدير فعلًا)، ثم مؤشرات، ثم الوضع الحالي، ثم تحليل الفترة.
2. **الحالة تُشفَّر بالشكل لا بالرقم فقط.** شارات (نقطة + نص)، شرائط استخدام الائتمان، أعمار ديون بلون رتبي، تنبيهات بأيقونات.
3. **الأمر الشائع بضغطة واحدة.** مندوب الميدان: زر «طلب جديد» مركزي في شريط الجوال، والطلبات تتحول لبطاقات قابلة للمس بدل جداول عريضة.
4. **لا شيء يختفي بلا بديل.** كل رسم له جدول بديل، والتلميح يعمل بلوحة المفاتيح، والمعلومة لا تعتمد على اللون وحده.
5. **الحركة تخدم الفهم:** رسم الخط يقود العين، والأشرطة تنمو من خط الأساس، والقوائم تدخل بتتابع، والاحتفال بعد الإنجاز فقط. كل ذلك يُحترم فيه «تقليل الحركة».

## الهوية: Bhub

الشعار ثلاث خلايا سداسية («أحواض تخزين») تلتقي في نقطة مركز واحدة — المركز (hub) الذي تلتقي عنده المبيعات والمخزون والتحصيل. الشعار الأصلي بخلفية كريمية وكلمة `bhub` بخط Nunito؛ والتعديلات لتناسب التطبيق:

| العنصر | التعديل |
|---|---|
| **الألوان** | ثابتة كما في الأصل: تيل `#0FB5AE`، مرجاني `#FF6B5B` (= `--c-coral`)، أصفر `#FFC93C`، حبر `#1D2B3A`، ورق `#F7F1E5`. تتوافق مع ألوان التمييز الموجودة في التطبيق، فلم تُغيَّر ألوان الواجهة ولا الرسوم المُدقَّقة (الأزرار والروابط تبقى بنفسجية لسلامة التباين). |
| **الكلمة** | حُوّلت إلى مسارات (Nunito 800، تباعد −1) فلا يحتاج الشعار إلى تنزيل خط ويعمل بنفس الشكل في SVG وPNG وداخل التطبيق (`src/components/logoPaths.ts`). |
| **الوضع الداكن** | العلامة تُعرض دائمًا فوق «بلاطة» كريمية (كأيقونة التطبيق) فلا يتغير ظهورها بين الفاتح والداكن؛ والكلمة ترث لون النص `currentColor`. |
| **الأيقونات** | `public/icon.svg` (بلاطة مستديرة، العلامة ≈ 64%)، `icon-maskable-512.png` (العلامة داخل المنطقة الآمنة 80%)، `apple-touch-icon.png` (مربع كامل)، `og.png` (1200×630 للمشاركة). المصدر الرئيسي `public/logo.svg` (800×800 كما في الأصل). |
| **الحركة** | عند الدخول تنمو الخلايا الثلاث من المركز بتتابع ثم تظهر نقطة المركز بارتداد؛ تنبض الخلايا عند التمرير؛ وفي شاشة الدخول تتنقل علامة مصغّرة بين «المراكز» على خط التوزيع. تتعطل الحركة مع «تقليل الحركة». |

## الألوان

| الدور | فاتح | داكن |
|---|---|---|
| السلسلة 1 — المبيعات | `#6d4aff` | `#8b73ff` |
| السلسلة 2 — التحصيل | `#009e8f` | `#00a899` |
| أعمار الديون: غير مستحق | `#9b97c4` | `#5a5690` |
| 1–30 / 31–60 / 61–90 / +90 يومًا | `#ee7f98` `#dc4a73` `#b52350` `#85163a` | `#9c3558` `#c64b73` `#e8688c` `#ff9db5` |

- **اللون يتبع الكيان:** المبيعات بنفسجي والتحصيل تيل في كل مكان (مؤشرات، حلقات المندوبين، الرسوم)، ولا يتغير بتغيّر الفلتر.
- **أعمار الديون رتبية** (لون واحد، الأقدم أبرز): أغمق في الفاتح، وأفتح في الداكن (يقلب المرساة).
- **الشرائط الاسمية** (مناطق، مندوبون، أصناف): لون واحد، لأن الطول يحمل القيمة والاسم يحمل الهوية.
- ألوان **الحالة** (أخضر/عنبري/أحمر) محجوزة للمعنى ولا تُستعمل كسلسلة، ودائمًا بنص ونقطة.
- الألوان الزخرفية للهوية (صور المندوبين الرمزية، دبابيس المناطق) لا تدخل في أي رسم مقارِن.

> كان اللون السابق للتحصيل (`#00b8a9`) يفشل هنا: تباينه 2.49:1 على الأبيض، وسطوعه خارج النطاق في الداكن. استُبدل بقيم نجحت في الوضعين.

لإعادة التحقق عند تغيير أي لون:

```bash
node validate_palette.js "#6d4aff,#009e8f" --mode light --surface "#ffffff"
node validate_palette.js "#8b73ff,#00a899" --mode dark  --surface "#181536"
node validate_palette.js "#ee7f98,#dc4a73,#b52350,#85163a" --mode light --surface "#ffffff" --ordinal
node validate_palette.js "#9c3558,#c64b73,#e8688c,#ff9db5" --mode dark  --surface "#181536" --ordinal
```

(السكربت من مهارة dataviz؛ القيم معرَّفة كمتغيرات CSS في `src/styles/tokens.css` تحت `--chart-*` و`--age-*`.)

## مواصفات الرسوم (`src/components/ui/Charts.tsx`)

| العنصر | المواصفة |
|---|---|
| الخطوط | 2px، نقطة الطرف بنصف قطر 4.5 وحلقة 2px بلون السطح |
| المساحة | غسل بشفافية 10% |
| الشبكة والمحاور | خطوط صلبة رفيعة (لا متقطعة)، وأرقام المحور مستديرة (`niceScale`) |
| الأشرطة | سُمك 10px، نهاية البيانات مستديرة 4px وخط الأساس مربّع، والقيمة عند طرف الشريط |
| التجزئة | فجوة 2px بلون السطح بين القطع، بلا حدود |
| وسيلة الإيضاح | موجودة عند ≥2 سلسلة، تعزل السلسلة بالضغط، والمفتاح مربّع للمساحات وخطّي في التلميح |
| التسميات | القيمة الأخيرة لكل سلسلة فقط، وبألوان النص (لا لون السلسلة) |
| التلميح | خط عمودي يلتقط أقرب يوم، القيمة أولًا ثم اسم السلسلة، ويعمل بالأسهم/Home/End |
| البديل | زر «جدول» في كل بطاقة رسم يعرض البيانات نفسها |
| الحركة | رسم الخط ونمو الأشرطة، وتتوقف مع «تقليل الحركة» |
| وضع التباين العالي | `forced-colors`: الخطوط بلون النص والسلسلة الثانية متقطعة |

لا توجد رسوم بمحورين، ولا دونات (استُبدلت بشريط أعمار رتبي لأن المقارنة بين القطع أصعب في الدائرة)، ولا ألوان تُولَّد بعد الثانية.

### بطاقة المؤشر (stat tile)
الاسم، ثم القيمة (خط متناسب وليس tabular)، ثم التغيّر **مقابل فترة مسمّاة** («عن أمس حتى الآن» — أمس حتى الساعة نفسها لا يوم كامل)، ثم خط مصغّر من 12 نقطة بلون خافت والفترة الحالية بلون التمييز. لون التغيّر = الاتجاه × هل الارتفاع جيد (للمبيعات نعم وللديون لا). العدّاد في البطل ≥ 48px.

### الفلتر
فلتر الفترة صف واحد فوق الرسوم التي يحكمها (المبيعات، المناطق، المندوبون)، وليس داخل البطاقات. لقطة الديون فوقه لأنها لا تتأثر بالفترة.

## أنماط التفاعل

- **لوحة الأوامر** (`Ctrl/⌘ + K` أو `/`): بحث موحّد في العملاء والطلبات والمنتجات والصفحات، وإجراءات سريعة (طلب جديد، تحصيل، عميل جديد)، بتنقل بالأسهم وEnter، وتطبيع عربي (الألف/الياء/التاء المربوطة/التشكيل).
- **النوافذ:** مكدّس نوافذ؛ Escape وTab يخصان العليا فقط (مثل نافذة تأكيد فوق درج).
- **الإنجاز:** احتفال خفيف بعد الطلب والتحصيل والتسليم، وحالة نجاح مع زر واتساب.
- **التحقق من الإدخال:** رسائل خطأ تحت الحقل، وأرقام عربية مقبولة في الحقول الرقمية.
- **الجوال:** زر «طلب جديد» مركزي، جداول → بطاقات، مبدّل أقسام «المزيد»، وبحث بالأيقونة.

## إمكانية الوصول
رابط «تخطَّ إلى المحتوى»، `aria-current` في التنقل، حلقات تركيز مرئية، مناطق حية للرسوم، أهداف لمس ≥ 34px، ودعم `prefers-reduced-motion` و`forced-colors`. ألوان الرسوم مُدقَّقة تباينيًا بالمدقّق، أما تباين بقية نصوص الواجهة فلم يُدقَّق بأداة وحدها.

## انحرافات معلنة عن المرجع
- **التدرج البنفسجي-التيل** في البطل وصفحة الدخول اختيار مقصود لطلب «الحيوية»، وبقية الواجهة هادئة.
- **رموز المنتجات (إيموجي)** بيانات المنتج نفسها (يختارها المستخدم) وليست زخرفة للواجهة؛ أُزيلت كل إيموجي الواجهة واستُبدلت بأيقونات موحّدة.
- **النسيج (texture)** لم يُنفَّذ (اختياري)؛ بديله الحالي: الجدول + التسميات + خطوط متقطعة في التباين العالي.
- خط Cairo مدمج مع الحزمة (يعمل دون إنترنت) ولم أقارن بخطوط أخرى.
